# WMC Python Practicals

Very simple Python programs for the 10 WMC practical experiments.

## Files

| File | Experiment |
| --- | --- |
| `frequency.py` | Frequency reuse |
| `dsss.py` | DSSS |
| `gsm.py` | GSM A3, A5 and A8 |
| `wireshark.py` | Wireshark filters |
| `iperf.py` | Throughput and latency |
| `wifi.py` | Packet Tracer Wi-Fi |
| `esp32.py` | ESP32 scan simulation |
| `cellular.py` | 3G, 4G and 5G |
| `comparison.py` | Wi-Fi, Bluetooth and Zigbee |
| `smart_home.py` | Smart home |

## Run in VS Code

Open the folder in VS Code. Open a file and click **Run Python File**.

You can also use the terminal:

```text
py frequency.py
```

Files 4, 6 and 7 are simple learning simulations. Real practical work still uses Wireshark, Cisco Packet Tracer and ESP32 hardware.
